Business Analyst Project Portfolio

A collection of business analysis case studies covering the full requirements-to-delivery lifecycle — stakeholder requirement gathering, process mapping (AS-IS/TO-BE), BRD/FRD documentation, user stories, requirement traceability, UAT, and dashboard delivery.

**Projects**
**Business Sales Performance Analysis & Power BI Dashboard**

Replaced manual, multi-day sales reporting with a real-time Power BI dashboard covering peak order times, peak days, top-5 best-sellers, and revenue trends.

Tools: Power BI (Desktop & Service) · MySQL · Excel · Power Query · DAX · draw.io

📄 Full documentation
Key result: Cut manual reporting effort by 45% via automated refresh and drill-through reporting
Used AS-IS & TO-BE diagrams

**Retail Sales Business Analysis & Excel Dashboard**
Replaced static, request-based sales reporting with a self-service Excel dashboard covering coffee type, roast, size, loyalty card status, and country-wise performance.

Tools: Microsoft Excel · Pivot Tables · Pivot Charts · Slicers · Timeline Filters

📄 Full documentation
Key result: Enabled direct measurement of loyalty program impact and instant segment-level visibility
Used AS-IS &	TO-BE diagrams
