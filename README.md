Pizza Sales Business Analysis & Power BI Dashboard

A business analysis project covering the full requirements-to-delivery lifecycle: stakeholder requirement gathering, process mapping, documentation, and a Power BI dashboard — built to replace manual, multi-day sales reporting with real-time, self-service analytics.

Tools: Power BI (Desktop & Service) · MySQL · Excel · Power Query · DAX · draw.io

Business Problem

Sales data existed in MySQL and Excel, but getting an answer to a simple question (peak hours, top-selling items, monthly revenue) required manual exports and pivot-table analysis — taking days and leaving staffing and inventory decisions based on guesswork rather than data.

What This Project Covers
Requirement Gathering — Simulated stakeholder interviews to capture business needs (owner, store manager)
BRD & FRD — Business and Functional Requirement Documents defining scope, objectives, and requirements
User Stories & Acceptance Criteria — Agile-style requirements with defined "done" conditions
Requirement Traceability Matrix (RTM) — Mapping requirements through to validation
UAT Test Cases — Verifying every dashboard metric against source data
Power BI Dashboard — 6-visual interactive dashboard with KPI scorecards, slicers, custom DAX measures, drill-through, bookmarks, scheduled refresh, and data gateway configuration

📄 Full documentation: Pizza_Sales_BA_Documentation.md

Key Results
Replaced manual, multi-day reporting with real-time dashboard access
Delivered KPIs for peak order times, peak days, top-5 best-selling items, and revenue trends
Cut manual reporting effort by 45% through automated refresh and drill-through reporting
